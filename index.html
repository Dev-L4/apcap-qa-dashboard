Por que dois números de arrecadação

Redis segura o crédito até o Motor rodar

Toda compra confirmada incrementa um delta no Redis. Esse delta só grava em Campanha.arrecadacao (o que o Admin mostra) quando o produtor de premiação roda para aquela campanha — por cron (produção) ou por acionamento do jogador (QA, cron desligado). Não é perda de dinheiro: é atraso de leitura até a próxima decisão do Motor. Fonte: flush-bolsas.service.ts + docs/premiacao.md §8.6.
